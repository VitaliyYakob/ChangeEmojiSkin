# ChangeEmojiSkin

AppleScript для настройки тона кожи эмодзи по умолчанию в панели «Эмодзи и символы» на macOS.
Можно задать общий тон, разные тона для обеих рук в 🤝 и исключения для отдельных эмодзи.
Параметры находятся в начале скрипта. Перед применением можно запустить предпросмотр, а при записи скрипт создаёт резервную копию.
